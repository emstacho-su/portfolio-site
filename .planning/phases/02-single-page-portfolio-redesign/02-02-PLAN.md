<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| client URL (`?s=`) -> client scroll | A reflected query value is read on the client and used as a scroll target. |
| inbound request -> Next config redirects | Legacy URLs cross the routing layer before render. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Tampering | reflected `?s=` query | mitigate | `s` is used only as `lenis.scrollTo('#'+s)` / id lookup; never written into innerHTML or used as a CSS/DOM selector beyond getElementById. Invalid ids no-op. (RESEARCH Security Domain.) |
| T-02-04 | Tampering (open redirect) | next.config.ts redirects() | mitigate | All `destination` values are static internal `/?s=` literals; no user input flows into the redirect target. |
| T-02-05 | Information disclosure | deleted route trees | accept | Removed routes 30x to `/?s=`; no sensitive data was served by them. |
</threat_model>
